# quality-gate-fix

## 目标

当 lint/test/build 失败时，快速定位并完成最小修复。

## 输入

- 失败命令与错误日志
- 最近变更文件列表

## 前置检查

- 先确认本地 Node 与 pnpm 版本与仓库要求一致。
- 先运行一次只读命令定位失败范围（单包优先）。

## 步骤

1. 先复现失败，再确认是否由本次改动引入。
2. 优先修复类型错误、导入路径错误、接口类型不一致。
3. 若是测试失败，先修业务逻辑，再更新断言。
4. 重新执行最小验证命令（按失败项）。
5. 最后运行 `pnpm lint` 与对应测试命令确认收敛。

## 输出检查

- 门禁恢复
- 修复范围最小化
- 无引入额外警告

## 最小验证命令

- `pnpm lint`
- `pnpm --filter <app> test`
